What is Sadaqah Code?

An open-source initiative building Islamic technology infrastructure — prayer reminders, Islamic calendars, focus modes, and more.

Core principle: technology should serve Islamic values, not corporate profits.

Why “Sadaqah Code”?

Sadaqah Jariyah is ongoing charity that keeps benefiting people long after the act. Open source works the same way.

  • Write code once → it benefits Muslims forever
  • Share knowledge → others build upon it
  • Create tools → the community improves them

Code as continuous charity.

What we stand for

01

Open Source Always

All code is public, auditable, and free. No proprietary lock-in.

02

Privacy First

No tracking or analytics. No data mining. Local storage by default.

03

Islamic Values

Accurate prayer times, a respected Hijri calendar, halal content prioritized.

04

Community Owned

Not controlled by one person or company. Contributions welcome, governance transparent.

05

Free Forever

No ads. No premium tiers. No paywalls.

06

No Exploitation

No addictive features. No dark patterns. Technology that respects users.

And above all: long-term impact — built to last.

Who we are

Developed by the FlagoDNA Team — developers who have built Islamic apps since 2020.

Sadaqah Code represents the community ownership and ethical framework behind the work.

  1. FlagoDNA builds and maintains the code.
  2. Sadaqah Code defines the mission and principles.
  3. The community contributes and benefits.
